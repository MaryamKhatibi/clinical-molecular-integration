# Data

The raw molecular and clinical files were obtained from:

**cBioPortal — Pancreatic Adenocarcinoma (TCGA, PanCancer Atlas)**

Study ID: `paad_tcga_pan_can_atlas_2018`

Raw source files and large intermediate data objects are intentionally excluded from the GitHub repository.

The analysis integrates:
- clinical patient data
- clinical sample data
- molecular gene-expression data

The final integrated cohort contains 177 samples with matching clinical and expression information.
